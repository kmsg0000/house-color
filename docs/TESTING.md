## 자동·모의 테스트로 확인한 것 (2026-11-16)
- ✅ ComfyUI 클라이언트(`desktop/comfy.js`) — 가짜 ComfyUI 서버 상대로 `/upload/image → /prompt → /history → /view` 전 과정, 결과 이미지 수신
- ✅ 노드 자동 탐지: 이미지 76(연결된 LoadImage, 81 제외) · 프롬프트 75:74 · 출력 9 · 해상도 75:80, 마스크 없음 경고
- ✅ 오류 처리: 그래픽 메모리 부족, ComfyUI 꺼짐, 화면 저장 형식 JSON, 노드 검증 오류 문구
- ✅ 휴대폰 중계(`desktop/relay.js`) — 토큰 없으면 401, 다른 출처 CORS 차단, 앱 출처 허용, 편집 요청 성공
- ✅ 앱 화면: 내 PC ComfyUI 설정(워크플로 불러오기·연결 테스트), 지우기 실행·진행률·비교·되돌리기, 사진 전체 편집
- ✅ Android 흐름(브라우저에서 네이티브 브리지 흉내): 연결 테스트 → 지우기 → 합성
- ✅ 원본 보존: 칠한 영역 밖 픽셀·원본 해상도 유지(합성 방식)

- ✅ ③ 자동 선택 안전장치: 회색 하늘+회색 벽 합성 사진에서 하늘로 번진 픽셀 135,000 → 0
- ✅ ① 정밀 선택(SAM 3.1): 가짜 ComfyUI 상대로 PC 중계 `/api/segment` 경유, 포함·제외 점 전달, 마스크 적용(`벽 선택(정밀)`), 수동 누르기 선택, 모델 없음/ComfyUI 꺼짐 오류 문구, 이상한 마스크면 기본 방식으로 대체
- ✅ ② 실사 마감: 칠한 영역 밖 픽셀 변화 0, 평균색 오차 1% 이내로 컬러칩 색 고정, 색을 바꾸면 자동 해제
- ⬜ 실제 ComfyUI + SAM 3.1 모델에서 정밀 선택 품질, 실제 FLUX 로 실사 마감 품질 (모의 테스트만 함)

## 사용자가 확인해야 할 것
### Windows PC (설치판)
- ⬜ 실제 ComfyUI Desktop + FLUX.2 Klein 워크플로 JSON 불러오기 → 연결 테스트(그래픽카드 이름·VRAM 표시)
- ⬜ 노란 차량 사진: 칠하고 "앞의 노란 차량" → 결과 품질, 소요 시간(첫 실행은 모델 로딩), 원본 해상도 유지(예: 1954×1230)
- ⬜ 나무 / 전봇대·전선 제거
- ⬜ 1MP / 2MP 비교, 12GB 에서 메모리 부족 여부
- ⬜ 취소 버튼으로 ComfyUI 작업이 멈추는지
- ⬜ 휴대폰 연결 켜기 → Windows 방화벽(개인 네트워크) → 주소·토큰 표시
- ⬜ OpenAI 키로 지우기(gpt-image-2), Gemini 키로 지우기 — 실제 키
- ⬜ 저장: JPEG / PNG

### Android (설치판)
- ⬜ 서명 키 교체 후 첫 설치: 기존 앱 삭제 → 새 APK 설치
- ⬜ PC 연결: 주소·토큰 → 연결 테스트 → 지우기 (네이티브 브리지 실제 동작)
- ⬜ 사진 고르기 / 카메라 / 갤러리 저장(JPEG·PNG)

### 공통 회귀
- ⬜ 색칠(자동 선택·브러시·색 고르기)·AI 명령·ChatGPT 로그인 기존 기능이 그대로 동작
