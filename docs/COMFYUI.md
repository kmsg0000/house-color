# 내 PC 의 ComfyUI 로 나무·차량 지우기 (무료, 인터넷 불필요)

RTX 5070 같은 그래픽카드가 있는 PC 에서 **ComfyUI** 를 켜 두면, PC 앱이 직접 ComfyUI 에 작업을 보내 지웁니다.
휴대폰 앱은 같은 Wi-Fi 의 PC 를 통해 같은 기능을 쓸 수 있습니다.

```
[PC 앱(Electron)] ──(내부 호출)──▶ ComfyUI 127.0.0.1:8188
       ▲
       │ 같은 Wi-Fi, 접근 토큰 필수 (기본 꺼짐)
[휴대폰 앱(Android)] ── 네이티브 HTTP ──▶ PC 앱 중계 :8766 ──▶ ComfyUI
```

## 1. 워크플로 준비 (처음 한 번)

1. ComfyUI 에서 사용할 이미지 편집 워크플로를 엽니다. (확인된 것: **FLUX.2 Klein 4B Distilled 이미지 편집**)
2. 메뉴 → **Export (API)** 로 저장합니다. (일반 "저장" 형식은 안 됩니다)
3. PC 앱 → 사진 열기 → 🤖 상자 **⚙ AI 설정** → **AI로 지우기 방식: 내 PC ComfyUI**
4. **📄 워크플로 JSON 불러오기** → 2번 파일 선택 → **연결 테스트**
   - "✅ 워크플로 준비됨 — 이미지 노드 76 · 프롬프트 노드 75:74 · 출력 노드 9 · 해상도 노드 75:80" 처럼 나오면 정상입니다.
   - 노드는 자동으로 찾습니다. LoadImage 가 여러 개면(예: 76, 81) **실제로 연결된 것(76)** 을 씁니다.
5. **저장**

## 2. 지우기

1. 지울 것(차량·나무·전봇대·전선)을 **빨갛게 넉넉히** 칠합니다.
2. "무엇을 지울까요?" 칸에 적습니다. 예: `앞의 노란 차량`, `전봇대와 전선`
3. **✨ AI로 지우기 (내 PC ComfyUI)** → 진행률이 표시되고, **취소** 할 수 있습니다.
4. **👀 지우기 전과 비교** 를 누르고 있으면 이전 사진이 보입니다. 마음에 안 들면 **↩ 지운 것 되돌리기**.

### 원본 보존 방식 (중요)
- 제공된 FLUX.2 Klein 워크플로에는 **마스크 입력이 없습니다.** 앱은 마스크를 ComfyUI 에 넣었다고 표시하지 않습니다.
- 대신 앱이 **칠한 곳 주변만 잘라서(작업 해상도에 맞춰) ComfyUI 에 보내고**, 돌아온 결과에서 **칠한 영역만** 원본에 부드럽게 합성합니다.
  - 칠하지 않은 부분의 픽셀과 **원본 해상도·비율은 그대로** 유지됩니다(예: 1954×1230 그대로).
  - 칠한 영역 안은 생성 모델이 추정해서 그린 것이라 실제 건물과 다를 수 있습니다.
- 지울 것을 적지 않으면, 칠한 곳을 빨갛게 표시한 사진을 보내 "빨간 부분을 지워라" 라고 지시합니다(정확도가 낮을 수 있음).
- **사진 전체 편집**(칠하지 않음)을 켜면 사진 전체를 다시 그리므로 건물 모양·창문·글자가 바뀌고, 결과는 작업 해상도(약 1MP)에서 원본 크기로 늘린 것이 됩니다.

### 작업 해상도
⚙ AI 설정의 **작업 해상도**(0.5/1/1.5/2MP)가 워크플로의 `ImageScaleToTotalPixels`(노드 75:80) 값으로 들어갑니다.
잘라낸 영역 기준이므로 1MP 로도 지울 부분은 충분히 선명합니다. 12GB 그래픽카드에서 메모리 부족 오류가 나면 낮추세요.

## 3. 휴대폰에서 PC 의 ComfyUI 쓰기

1. PC 앱 → ⚙ AI 설정 → 내 PC ComfyUI → **📱 휴대폰에서 이 PC 의 ComfyUI 쓰기 → 켜기**
   - Windows 방화벽 창이 뜨면 **개인 네트워크만** 허용하세요.
   - 화면에 `PC 주소: http://192.168.x.x:8766` 와 `접근 토큰` 이 표시됩니다.
2. 휴대폰 앱 → ⚙ AI 설정 → **AI로 지우기 방식: PC 연결 (같은 Wi-Fi)** → 주소·토큰 입력 → **연결 테스트** → 저장
3. 사용 방법은 PC 와 같습니다.

보안:
- 중계 서버는 **기본 꺼짐**, 켤 때만 열리고, 모든 요청에 토큰이 필요합니다. **토큰 새로 만들기** 로 언제든 바꿀 수 있습니다.
- 휴대폰 앱은 **사설망 주소(192.168.x.x 등)로만** 요청합니다.
- **공유기 포트포워딩 등으로 인터넷에 공개하지 마세요.** (중계는 HTTP 이며 같은 집 Wi-Fi 용입니다)

## 4. 🎯 정밀 선택 (SAM 3.1) — 칠할 곳을 정확히 고르기

AI(ChatGPT·Gemini 등)는 "여기가 벽" 이라고 **점만** 찍어 줍니다. 그 점에서 칠할 영역을 넓히는 일을
예전에는 앱이 "비슷한 색 따라가기" 로 했는데, 회색 벽·흐린 하늘·유리창처럼 색이 비슷하면 번졌습니다.
ComfyUI 에 들어 있는 **SAM 3.1** 이 그 점(과 제외할 점)을 받아 벽만 정확히 잘라 줍니다.
**색은 계속 앱이 칠하므로 노루페인트 컬러칩 색 번호가 그대로 유지됩니다.**

설치 (처음 한 번, 커스텀 노드 필요 없음):
1. ComfyUI 를 **최신 버전으로 업데이트** (SAM 3.1 노드 `SAM3_Detect` 가 기본 내장된 버전).
2. 모델 받기: [sam3.1_multiplex_fp16.safetensors](https://huggingface.co/Comfy-Org/sam3.1/resolve/main/checkpoints/sam3.1_multiplex_fp16.safetensors) (약 1.7GB)
3. `ComfyUI/models/checkpoints/` 폴더에 넣고 ComfyUI 재시작.
4. 앱 ⚙ AI 설정 → AI로 지우기 방식 **내 PC ComfyUI**(또는 휴대폰은 **PC 연결**) → **🎯 정밀 선택 (SAM 3.1)** 체크 → 저장.

쓰는 곳:
- AI에게 시키기: "벽을 베이지로" → AI가 찍은 점 + 제외할 점(하늘·유리·간판)으로 SAM 이 선택. 결과에 `벽 선택(정밀)` 이라고 표시됩니다.
- 직접 고치기 → 칠할 곳: 벽을 누르면 SAM 이 고릅니다. **🎯 AI 정밀 선택: 켜짐/꺼짐** 버튼으로 기본 방식과 바꿀 수 있어요.
- SAM 이 안 되면(모델 없음·ComfyUI 꺼짐) 자동으로 기본 방식으로 고르고 이유를 알려 줍니다.

> SAM 을 안 써도, 앱의 기본 방식이 이제 **하늘을 자동으로 빼고**, 영역이 너무 넓어지면 범위를 줄여 다시 고릅니다.

## 5. ✨ 실사 마감 (생성형 재도색, 선택 사항)

완성 화면의 **✨ 실사 마감** 버튼. 칠한 벽 부분만 FLUX(또는 OpenAI·Gemini)가 빛·그림자·질감을 자연스럽게 다시 그립니다.
- 칠한 벽 **안쪽에만** 합성 → 창문·간판·하늘은 원본 그대로.
- AI가 색을 바꿔 그려도, 부분별 **평균색을 컬러칩 색으로 되돌려 고정** → 색 번호와 맞는 색.
- 그래도 미세한 무늬·명암은 AI가 만든 것이라 실제와 다를 수 있습니다. 색을 다시 고르면 자동으로 꺼지고, **실사 마감 끄기** 로 언제든 원래대로.

## 6. 문제 해결

| 증상 | 확인 |
|---|---|
| "ComfyUI 에 연결할 수 없어요" | ComfyUI Desktop 이 켜져 있는지, 주소가 `http://127.0.0.1:8188` 인지 |
| "화면 저장 형식입니다" | ComfyUI 에서 **Export (API)** 로 다시 내보내기 |
| "그래픽카드 메모리가 부족해요" | 작업 해상도를 낮추거나 칠한 영역을 나눠서 |
| 노드 오류 | 워크플로가 ComfyUI 에서 단독으로 잘 도는지 먼저 확인 |
| 휴대폰 "연결 실패" | 같은 Wi-Fi 인지, PC 앱에서 휴대폰 연결이 켜져 있는지, 방화벽 허용, 주소·토큰 |
| "SAM 3.1 노드가 없어요" | ComfyUI 업데이트 (Manager → Update ComfyUI) |
| "SAM 3.1 모델 파일이 없어요" | `sam3.1_multiplex_fp16.safetensors` 를 `models/checkpoints` 에 |
| 정밀 선택이 엉뚱한 곳을 고름 | ↩ 되돌리기 후 벽의 더 넓은 곳을 누르거나, 버튼으로 끄고 기본 방식 사용 |
| 결과가 원본과 다르게 변형 | 칠한 영역만 반영되므로 칠하는 범위를 줄이고, "무엇을 지울지" 를 구체적으로 |
