🤖 AI에게 말로 시키기

1. 건물 사진을 골라 주세요

휴대폰에서는 바로 사진을 찍을 수도 있어요.

💡 건물 정면이 잘 보이고, 밝은 낮에 찍은 사진이 가장 잘 됩니다.
사진은 이 기기 안에서만 처리되고 어디에도 보내지지 않아요.

2. AI에게 시켜 보세요

나무 지우기, 칠할 곳 찾기, 색칠까지 말 한마디로 됩니다. 결과가 조금 틀리면 아래 ✋ 직접 고치기로 손볼 수 있어요.

💬 ChatGPT 채팅창에 말씀하세요

예: "창틀은 흰색으로", "벽을 좀 더 밝게", "앞의 나무도 지워줘". 여기 적어도 채팅으로 보내집니다.

지금 칠한 색

2. 방해되는 것 지우기

나무·자동차·전깃줄처럼 가리는 것이 있으면 손가락(마우스)으로 빨갛게 칠한 뒤 아래 지우기를 누르세요. 없으면 건너뛰어도 됩니다.

붓 크기
💡 지울 것보다 조금 넉넉하게 칠하면 더 자연스럽습니다. 큰 물체는 여러 번 나눠서 지우면 좋아요.

3. 칠할 곳을 눌러 주세요

사진에서 칠하고 싶은 벽을 한 번 누르면 파랗게 선택됩니다. 여러 군데 누르면 계속 더해져요.

5. 완성!

아래 버튼을 누르고 있으면 원래 사진이 보여요.

색 번호는 그대로 유지하고, 칠한 벽 안에서만 다듬어요. 창문·간판·하늘은 건드리지 않아요. (10~60초)

✨ AI로 지우기 방식

작업 해상도
워크플로를 아직 불러오지 않았어요.
📱 휴대폰에서 이 PC의 ComfyUI 쓰기

같은 Wi-Fi 안에서만 쓰세요. 공유기 포트포워딩(인터넷 공개)은 하지 마세요. 처음 켤 때 Windows 방화벽 창이 뜨면 개인 네트워크만 허용하세요.

꺼져 있음
PC 앱의 ⚙ AI 설정 → 내 PC ComfyUI → 📱 휴대폰에서 쓰기 를 켜면 주소와 토큰이 나와요.
칠할 색 고르기
사용 방법
1. 건물 사진을 고릅니다.
2. 나무나 차가 가리면 빨갛게 칠하고 [지우기]를 누릅니다. (안 해도 됨)
3. 칠할 벽을 손가락으로 한 번 누릅니다. 너무 적게/많이 잡히면 [더 넓게]/[더 좁게].
4. 마음에 드는 색을 누르면 바로 바뀝니다.
5. [저장]을 누르면 사진으로 남습니다.

화면이 작으면 오른쪽 아래 ＋ 버튼으로 크게 보고, ✋ 버튼을 누른 뒤 화면을 밀어서 옮기세요.
